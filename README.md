# Scal
Scal is a friendly scam alert app that checks for scam texts, messages, and emails through a friendly chameleon pal named Scal. If you think a message is a scam or aren't sure about something, ask Scal! Scal As of its current prototype, Scal is only able to look at what messages you give it, bute hopfully it'll be able to look at messages by itself
